## 2026-10-03 — локальний сценарій за дизайн-референсом власника

Головна містить поле опису без категорій; далі підтвердження, лише вибір організації
та негайний перехід до наступних кроків. Польську мову, приватність, джерела
й обов'язкове зіставлення з інноваціями збережено.
Реальні організації не надані: UI працює з окремими явно синтетичними fixtures,
дозволеними тільки в локальному fixtures-режимі. Не перейменовуємо інновації на організації.
Довідник з контактами й перевіркою залишається наступною інтеграцією.

# Canvas — рішення 2026-10-04

Власник попросив пріоритезувати функціональність звичайних шляхів. Після Q1–Q3
додано Q5 у наявну картку, без другого незалежного редактора/сутності. Вивчено
всі три сторінки оригіналу ROPS/InnoAGH Social Innovation Canvas v1.0 05.05.2026:
https://rops.krakow.pl/mpliki/IS/Moj_folder/INNO_AGH_-_SOCIAL_CANVAS.pdf.
13 необов'язкових текстових полів групують теми трьох сторінок; problem/solution/
audience/stage повторно використовуються з картки. Шкали й чекбокси оригіналу не
відтворені один-до-одного, UI прямо називає це спрощеним робочим аркушем і дає
посилання на першоджерело. Canvas збережено в існуючому ideas.record JSONB.
AI розвиває активований Canvas лише як пропозицію; stage захищений сервером,
невідоме залишається питанням/гіпотезою. Browser print використовує приватний
серверний preview з уже збереженої версії. Нових залежностей/міграцій для Canvas немає.
